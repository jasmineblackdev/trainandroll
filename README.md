# Train&Roll

DOT health tracking & compliance platform for commercial drivers.

## Projects

| Directory | Description |
|-----------|-------------|
| `mobile/` | Driver-facing mobile app (React + Capacitor) |
| `website/` | Marketing website (React) |
| `fleet/` | Fleet admin dashboard — company-facing software (React) |
| `api/` | Backend API server (Node.js/Express) |

## Getting Started

```bash
# Install dependencies for a sub-project
cd mobile && npm install
cd website && npm install
cd fleet && npm install
cd api && npm install
```

## Tech Stack

- **Mobile & Web:** React, Vite, Lucide Icons
- **API:** Node.js, Express
- **Mobile:** Capacitor (iOS & Android)
